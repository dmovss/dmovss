### Professional Summary
Software Engineer with over 3 years of commercial experience specializing in front-end development and high-performance web applications. ### Core Technical Expertise
* **Architecture & Frameworks:** Deep proficiency in React.js and Next.js (including SSR, SSG, and App Router). Extensive experience in building reusable component libraries and maintaining scalable frontend architectures.
* **State Management & Data:** Advanced implementation of state management systems using Redux, Pinia, and MobX. Expert handling of data fetching and caching with GraphQL (Apollo Client) and REST APIs.
* **Real-time Systems:** Significant experience in implementing bidirectional communication using WebSockets and SignalR for live-data synchronization.
* **Graphics & Performance:** Specialized knowledge in programmatically generated graphics and animations via Pixi.js, GSAP, and HTML5 Canvas API. Focused on achieving 60 FPS performance and optimizing browser rendering cycles.
* **Quality & Infrastructure:** Strong commitment to code quality through unit/integration testing (Jest) and rigorous code reviews. Proficient in managing CI/CD pipelines, Docker containerization, and cloud-based deployments (AWS, GCP).
